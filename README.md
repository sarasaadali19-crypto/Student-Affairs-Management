Student Affairs Management System

1. Project Description

This project is a Student Affairs Management System developed using C++.

It helps manage student information, including names, IDs, departments, and grades.

2. Project Objectives

- Add student information.
- Display student records.
- Update student grades.
- Organize student data.

3. OOP Concepts Used

- Classes and Objects.
- Inheritance.
- Encapsulation.
- Constructors and Destructors.
- Polymorphism.
- Virtual Functions.
- Public, Private, and Protected.

4. Programming Language

C++

5. How to Run

1. Open the project in a C++ compiler.
2. Compile the main.cpp file.
3. Run the program.

6. Conclusion

This project demonstrates the use of Object-Oriented Programming concepts in C++ through a simple Student Affairs Management System.
